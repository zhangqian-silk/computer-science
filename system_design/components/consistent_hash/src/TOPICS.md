# 一致性哈希示例

本目录提供三种路由算法的教学级实现，并对比它们的负载均衡性与扩容迁移比例。

上层原理文档见 [consistent_hash.md](../consistent_hash.md)。

## 目录结构

- ring.go：一致性哈希环 + 虚拟节点（Add/Remove/Get，有序数组 + 二分）
- jump.go：跳跃一致性哈希（Jump Consistent Hash，O(1) 内存）
- hrw.go：HRW / Rendezvous（最高随机权重）
- main.go：对三种方案做负载相对标准差与 4→5 节点迁移比例的对比实验

## 快速开始

在当前目录执行：

```bash
go run .
```

## 观察点

- 环方案：虚拟节点从 1→200，负载相对标准差从数十 % 收敛到个位数 %（印证 CV≈1/√V）。
- 三种方案 4→5 节点的迁移比例都接近 1/(N+1)≈20%，印证「最小扰动」。
- Jump 分布最均匀且零内存，但只支持尾部增删；HRW 支持任意增删但查询 O(N)。
