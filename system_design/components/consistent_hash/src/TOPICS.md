# 一致性哈希示例

本目录提供教学级一致性哈希环实现，演示虚拟节点对负载均衡的影响，以及增删节点时的迁移比例。

上层原理文档见 [consistent_hash.md](../consistent_hash.md)。

## 目录结构

- ring.go：带虚拟节点的一致性哈希环（Add/Remove/Get）
- main.go：分布均匀度与迁移比例示例

## 快速开始

在当前目录执行：

```bash
go run .
```

## 观察点

- 虚拟节点数从 1 增大到 200，各物理节点分到的 key 数量逐渐趋于均衡。
- 移除一个节点后，迁移比例趋近 1/N，而不是接近 100%（取模分片的表现）。
