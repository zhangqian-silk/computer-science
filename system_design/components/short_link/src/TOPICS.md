# 短链示例

本目录提供教学级短链服务：发号器（自增 ID）+ 62 进制编码 + 内存存储，演示生成、复用与解析。

上层原理文档见 [short_link.md](../short_link.md)。

## 目录结构

- base62.go：62 进制编解码
- store.go：发号 + 生成 + 解析（相同长链复用短码）
- main.go：编解码往返与短链生成/解析示例

## 快速开始

在当前目录执行：

```bash
go run .
```

## 观察点

- ID 越大短码越长，但增长很慢（62 进制）。
- 相同长链多次提交复用同一短码。
- 短码可无损解码回原始 ID。
