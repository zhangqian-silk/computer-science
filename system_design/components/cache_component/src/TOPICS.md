# 缓存组件示例

本目录提供教学级 LRU 缓存（哈希表 + 双向链表），演示 O(1) 读写与淘汰顺序。

上层原理文档见 [cache_component.md](../cache_component.md)。

## 目录结构

- lru.go：LRU 缓存（Get/Put/淘汰 + 命中统计）
- main.go：固定访问序列的命中率与淘汰过程演示

## 快速开始

在当前目录执行：

```bash
go run .
```

## 观察点

- 命中会把 key 提升到最近端，避免热点被淘汰。
- 容量满时淘汰链表尾部（最久未使用）的 key。
- 输出末尾给出整体命中率。
