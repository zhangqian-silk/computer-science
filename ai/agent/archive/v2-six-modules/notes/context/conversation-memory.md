# 长期记忆：写入、召回与更新

长期记忆是经过选择、能够跨任务复用的信息集合。它可以记录用户明确偏好、项目约定或过去任务的经验；不是全部聊天记录的另一个名字，也不是模型参数在每次对话后自动更新。

普通对话记录的保存与加载属于会话存取，是长期记忆的来源，但保存不等于跨任务复用。长期记忆在此之上增加一个决定：什么值得在未来重新使用。

还要把跨任务的长期记忆与任务内的结构化笔记区分开。后者是 Agent 在一次长任务中写到窗口之外的暂存文件（待办清单、`NOTES.md`），用于在几十次工具调用间维持进度与依赖，任务结束通常即可丢弃；只有其中被判定值得复用的部分，才提升为下面讨论的长期记忆。任务内笔记作为绕开窗口限制的手段，见[长程任务的上下文策略](context-engineering.md)。

---

## 一、记忆的类型与作用域

| 类型 | 例子 | 使用方式 |
| --- | --- | --- |
| 事实性记忆 | 项目文档统一使用中文 | 作为当前任务的背景 |
| 偏好记忆 | 用户要求回答先给结论 | 在适用场景调整表达 |
| 经历性记忆 | 某次检查发现配置覆盖来自环境变量 | 作为过去事件回查 |
| 程序性知识 | 检查配置应区分声明值与运行值 | 作为操作方法参考 |

这是便于设计的分类，不要求每类使用不同数据库。更重要的是作用域：个人偏好不能覆盖团队规则，项目 A 的约定不应自动应用到项目 B，某次任务的临时要求也不必提升为永久偏好。[[24]](../references.md#source-langgraph-memory)

## 二、从观察到记忆条目

```mermaid
flowchart LR
	O["消息或任务反馈"] --> C["候选提取"]
	C --> V["核对主体与证据"]
	V --> W["写入记忆"]
	W --> R["按任务召回"]
	R --> U["确认或更新"]
```

图中「候选」还不是可依赖的事实。例如「这次请详细一点」只能说明本次偏好；「以后此项目都用中文」才提供更明确的跨任务意图。若信息涉及敏感个人资料，应先确定是否确有保存必要和相应授权。

```json
{
	"memory_id": "memory-7",
	"scope": "project-a",
	"kind": "preference",
	"content": "项目说明使用中文，保留英文技术术语。",
	"source": "session-17/msg-8",
	"status": "active",
	"revision": 1
}
```

内容说明记住什么，来源说明为什么这么记，作用域说明在哪里适用。对会变化的事实还应记录观察时间和有效条件。模型提取出的置信度只能用于筛选，不能替代来源。

写入可以发生在对话中，也可以在任务结束后批量整理。即时写入更快可用，但容易吸收尚未确认的推测；结束后整理更容易依据完整结果，但不能假设所有任务都会正常结束。

## 三、召回与注入

召回先限定用户、项目和访问权限，再按当前任务筛选主题；过期、被替换或已撤销的条目不应继续作为有效背景。最终只注入必要信息，并使模型能区分「用户偏好」「历史经验」与「当前事实」。

以「解释配置」为例：

- 中文文档偏好可能相关。
- 上次检查的端口值只是旧观察，不能证明当前端口。
- 另一个项目的部署步骤应被作用域过滤。

记忆很多时可以使用关键词、向量或结构化字段检索，但检索分数高不代表条目可信。若条目来源是旧模型回答，应避免把该回答包装成用户明确确认的事实。

## 四、更新、冲突与删除

更新不只是追加一条新文本。用户把语言约定从中文改为英文时，需要让旧条目失效并建立替代关系，否则未来召回可能同时返回两种规则。

| 情况 | 处理含义 |
| --- | --- |
| 同义重复 | 合并内容，保留来源 |
| 明确替代 | 新版本生效，旧版本标记被替换 |
| 不同作用域 | 分开保存，不强行消解 |
| 来源冲突 | 保留冲突状态，必要时请求确认 |
| 用户要求遗忘 | 删除或停止使用相应条目，并处理派生副本 |

「用户不喜欢详细回答」和「这次需要详细说明」不一定矛盾：一个是默认偏好，一个是本次明确要求。有效性判断需要范围和时间，而不能只比较相似度。

删除还涉及索引、摘要和缓存中的派生内容。若系统保留审计记录，应说明它与用于个性化召回的记忆有不同保留目的，不能声称已从所有介质彻底消除却仍继续使用。

---

## 五、记忆是否真的有帮助

用成对任务检查「有记忆」与「无记忆」的区别，至少包括正确偏好、无关偏好、过期事实、跨项目同名对象和明确纠正五类情况。

关注写入准确性、召回相关性、更新及时性、跨域误用率，以及最终任务表现。重复使用旧错误导致回答更一致，并不是可靠性提高。

学习自检：保存完整历史为什么不等于长期记忆？因为后者额外决定了选择、作用域、有效性与复用；为什么记忆不能代替事实读取？因为过去发生过或曾经成立，不代表现在仍成立。
