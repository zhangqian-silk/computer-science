# 离线机制实验

这些程序与正文中的教学设计对应，不是 Claude Code、Codex、Pi 或 DSH 的移植，也不是生产级 Agent SDK。

## 环境与运行

Python 3.11 及以上，标准库即可运行离线部分。无需模型账号、网络或 API Key。

```bash
cd examples
python demo.py
python -m unittest discover -s . -v
```

`demo.py` 展示单次生成、单次工具执行直接返回、两次模型交互的闭环。模型为确定性脚本，工具只返回内存中的端口；`answer_proposed` 明确不等于任务经过独立验收。

`test_core.py` 验证模型调用与结果关联、上下文原子组、注册表快照、审批身份、预算预留、增量组装和操作恢复。崩溃测试会在临时目录中启动标准库子进程（使用 `-S` 跳过站点启动代码），写入两个模拟 SQLite 数据库，然后以 17 退出。该退出是测试的一部分；测试父进程进行查询对账并清理临时目录。

## 文件对应

| 文件 | 用途 |
| --- | --- |
| `core.py` | 教学组件的具体实现，无真实供应商适配 |
| `demo.py` | 三种调用路径的可观察差异 |
| `crash_worker.py` | 仅供测试调用的受控崩溃子进程 |
| `test_core.py` | 标准库单元与子进程恢复测试 |
| `live_api.py` | 可选 OpenAI SDK 示例，未实际运行 |

运行 `live_api.py` 需要单独安装并固定 `openai` SDK 版本，设置 `OPENAI_API_KEY` 与 `OPENAI_MODEL`，且可能产生费用。不要把凭据写入仓库。离线测试不证明此接口与你的账户、模型版本或代理配置兼容。

## 明确的适用边界

工具参数验证只演示名称、精确字段集合和 JSON 可表示性，不实现完整 JSON Schema；示例工具都是只读的。读工具异常可作为观察回填，写工具异常必须依靠实际操作状态决定恢复，不应照搬一个通用 except 后重试。

`JsonLineStream` 是自定义 JSONL 教学协议，不是 SSE、MCP、Codex App Server 或 Pi RPC。它验证 UTF-8 分块、条目结束与响应结束的区别，真实协议需另写适配器和保真测试。

注册表快照固定函数引用，并不隔离函数闭包里的可变资源；热卸载与资源回收需要生产宿主提供生命周期管理。审批绑定的数据需要应用从可信执行身份构造。示例没有用户认证或跨进程审批锁。

预算以整数单位演示原子预留，未知最终供应商费用不能据此自动变成硬上限。真实调用要记录未知使用量和超额，而不是强行截断账目。

模拟远端主动提供唯一操作键与冲突检查，因此恢复测试能验证“已产生一个模拟效果，查询后不重复执行”。本地 SQLite 账本不能替没有幂等接口的真实远端创造 exactly-once。测试不覆盖断电、网络分区、跨机写入或真实沙箱。
