# 数学与符号约定

数学公式用于精确定义对象、计算过程和评价口径。符号只有在对象类型、形状、求和范围与归一化方式明确时才有意义；同一个字母脱离局部定义不能单独解释。

---

## 公式排版

行内公式使用 `$...$`，例如 $h_t\in\mathbb{R}^{d_h}$；独立公式使用 `$$...$$`：

$$
h_t=\tanh(W_xx_t+W_hh_{t-1}+b)
$$

排版遵循以下约定：

- 多字符函数使用正体，例如 $\operatorname{softmax}$、$\operatorname{PPL}$、$\exp$；
- 自然语言、单位和特殊 token 使用 $\text{...}$，例如 $128\text{ KiB}$、$\text{<EOS>}$；
- 向量转置写作 $x^\top$，不使用容易与指数混淆的普通字母 `T`；
- 数值中的千位使用细空格，例如 $100\,000$；
- 公式前先说明计算目标，公式后解释符号、形状和结果含义。

---

## 标量、向量、矩阵与集合

| 对象 | 记法 | 例子 |
| --- | --- | --- |
| 标量 | 小写拉丁字母或希腊字母 | $t,n,d,\eta,\tau$ |
| 向量 | 小写字母，并通过上下文或形状声明 | $x_t,h_t,q_i\in\mathbb{R}^d$ |
| 矩阵或批量张量 | 大写字母 | $X,W,Q,K,V$ |
| 集合 | 花体大写字母 | 词表 $\mathcal{V}$、数据集 $\mathcal{D}$ |
| 函数 | 带参数的符号或正体名称 | $f_\theta(x)$、$C(h,w)$、$\operatorname{softmax}(z)$ |

向量不额外使用粗体，以避免长公式中同时混用 $\boldsymbol{x}$ 与 $x$。对象类型由定义和形状确定。大写字母也可以表示函数值矩阵，例如隐藏状态 $H$；计数函数 $C(\cdot)$ 等局部定义属于明确例外。

集合与矩阵应尽量避免共用符号。词表统一记为 $\mathcal{V}$，Attention 中的 $V$ 专指 Value 矩阵。

## 索引、长度与维度

| 符号 | 统一含义 |
| --- | --- |
| $i,j$ | 通用位置、样本或候选索引，范围由公式声明 |
| $t$ | 时间步或自回归 token 位置 |
| $\ell$ | 网络层索引；作为损失时必须写成带参数的 $\ell(\cdot)$ |
| $B$ | batch 大小 |
| $\mathcal{B}$ | 一个 mini-batch 中的样本集合，满足 $|\mathcal{B}|=B$ |
| $T$ | 时间序列或语言序列长度 |
| $n$ | 不强调时间语义的元素数量或序列长度 |
| $n_q,n_k$ | Attention 中 query 与 key 的数量 |
| $n_{\text{head}}$ | Query/Attention 头数 |
| $n_{\text{kv}}$ | Key/Value 头数 |
| $d$ | 局部上下文中的通用向量维度 |
| $d_{\text{model}}$ | 模型隐藏宽度 |
| $d_{\text{head}}$ | 单个 Attention 头的维度 |
| $d_{\text{ff}}$ | 前馈网络中间维度 |
| $d_x,d_h$ | 循环网络的输入维度与隐藏维度 |

$T$ 和 $n$ 都可表示序列长度，但同一页面内应选择一种主记法。涉及时间递推或语言概率时优先使用 $T$；强调矩阵形状或通用集合时可以使用 $n$。

张量第一次出现时应给出形状。例如：

$$
X\in\mathbb{R}^{B\times n\times d_{\text{model}}}
$$

表示一个 batch 中有 $B$ 条序列，每条有 $n$ 个位置，每个位置由 $d_{\text{model}}$ 维向量表示。

## 序列与模型状态

| 符号 | 含义 |
| --- | --- |
| $w_t$ | 第 $t$ 个离散语言 token |
| $x_t$ | 第 $t$ 个通用输入或输入向量 |
| $y_t$ | 第 $t$ 个监督目标或输出 |
| $\hat{y}_t$ | 模型预测 |
| $h_t$ | 第 $t$ 个隐藏状态 |
| $H=[h_1,\ldots,h_n]$ | 一组逐位置隐藏状态 |
| $c_t$ | 局部定义的上下文向量或 LSTM 细胞状态 |

$c_t$ 的含义依赖页面：Attention 中通常表示加权上下文，LSTM 中表示细胞状态。两类变量不会在同一推导中混用；使用前必须明确说明。

特殊 token 在正文中写作 `<BOS>`、`<EOS>`、`<PAD>`、`<UNK>`；进入数学公式时使用 $\text{<BOS>}$ 等正体形式。

## 概率、logits 与损失

事件或条件分布使用大写 $P$：

$$
P(w_t\mid w_{<t})
$$

概率向量或单个概率分量使用小写 $p$，未归一化分数使用 $z$：

$$
p_i
=
\frac{\exp(z_i)}{\sum_j\exp(z_j)}
$$

| 符号 | 含义 |
| --- | --- |
| $z$ | logits，尚未归一化的实数分数 |
| $p_i$ | 第 $i$ 个候选的概率 |
| $P(A\mid B)$ | 给定 $B$ 时事件 $A$ 的条件概率 |
| $\ell$ | 单样本、单位置或局部损失 |
| $\mathcal{L}$ | batch、序列或数据集上的聚合目标 |
| $\theta$ | 模型中所有待讨论参数的集合 |
| $\eta$ | 学习率 |
| $\tau$ | softmax 或对比学习温度 |

若未额外说明，$\log$ 表示自然对数；以 2 为底时显式写作 $\log_2$。

损失是求和还是平均必须显式写出。以下两式数值不同：

$$
\mathcal{L}_{\text{sum}}=\sum_{t=1}^{T}\ell_t
$$

$$
\mathcal{L}_{\text{mean}}=\frac{1}{T}\sum_{t=1}^{T}\ell_t
$$

报告 NLL、PPL 或不同 batch 的训练 loss 时，必须同时说明归一化单位。

## 线性代数与常用算子

| 记法 | 含义 |
| --- | --- |
| $u^\top v$ | 向量内积 |
| $AB$ | 矩阵乘法 |
| $a\odot b$ | 逐元素乘法 |
| $[a;b]$ | 沿特征维拼接 |
| $\|x\|_2$ | $L_2$ 范数 |
| $\operatorname{norm}(x)$ | 按局部定义归一化，通常指 $L_2$ 归一化 |
| $\mathbb{1}[A]$ | 条件 $A$ 成立时为 1，否则为 0 |
| $\max(a,0)$ | 标量最大值；向量输入时逐元素计算 |
| $\arg\max_i z_i$ | 使 $z_i$ 最大的索引 |

矩阵乘法必须满足相邻维度相等。例如：

$$
X\in\mathbb{R}^{n\times d_{\text{model}}},\qquad
W^Q\in\mathbb{R}^{d_{\text{model}}\times d_k}
$$

因此：

$$
Q=XW^Q\in\mathbb{R}^{n\times d_k}
$$

公式不仅给出计算，还应允许读者通过形状检查发现转置或维度错误。

## Attention 专用符号

| 符号 | 含义 |
| --- | --- |
| $Q$、$q_i$ | Query 矩阵及第 $i$ 个 query |
| $K$、$k_j$ | Key 矩阵及第 $j$ 个 key |
| $V$、$v_j$ | Value 矩阵及第 $j$ 个 value |
| $M$ | 加到 score 上的可见性 mask |
| $\alpha_{ij}$ | query $i$ 对 key $j$ 的归一化权重 |
| $d_k,d_v$ | Key/Query 与 Value 的局部维度 |

标准缩放点积 Attention 为：

$$
S=\frac{QK^\top}{\sqrt{d_k}}+M
$$

$$
A=\operatorname{softmax}(S),\qquad H=AV
$$

若未额外说明，softmax 沿每个 query 对应的 key 维计算，也就是对 $S$ 的每一行归一化。$M_{ij}=-\infty$ 表示该连接在归一化后权重为 0。

头数使用 $n_{\text{head}}$，不使用 $H$，避免与隐藏状态矩阵 $H$ 混淆。缓存中的 KV 头数使用 $n_{\text{kv}}$。

## 局部符号与希腊字母

部分符号只能在专题内定义：

| 符号 | 常见局部含义 |
| --- | --- |
| $\alpha$ | Attention 权重、LoRA 缩放或其他混合系数 |
| $\lambda$ | 插值权重、回退质量或正则项权重 |
| $\gamma$ | 阈值、折扣或缩放参数 |
| $r$ | LoRA rank、排名或其他局部整数 |
| $k$ | Top-K、负样本数或稀疏连接数 |

这些字母可以跨页面承担不同职责，但必须在第一次出现前定义，并且同一推导中不复用。温度优先保留为 $\tau$；任务类型、实验切片等枚举变量使用 $\kappa$ 等其他符号。LoRA 的 $A,B$、MoE 的专家数 $E$ 等专题变量可以覆盖通用字母含义，但必须在局部给出形状或取值范围。

---

## 梯度记法

一般梯度写作：

$$
\frac{\partial\mathcal{L}}{\partial W}
$$

需要连续推导多个中间变量时，可以用上横线表示反向传播到该变量的梯度：

$$
\bar{h}_t
\equiv
\frac{\partial\mathcal{L}}{\partial h_t}
$$

上横线不是变量的平均值。采用这种简写时，页面应在第一次使用处给出等价定义。

## 阅读公式的顺序

面对一个新公式，可以依次检查：

1. 输出是什么标量、向量、矩阵或概率分布；
2. 每个输入的形状是什么；
3. 求和、softmax 或归一化沿哪个维度进行；
4. 哪些量是数据，哪些量是可训练参数；
5. 训练时损失怎样回传，推理时哪些状态会被保存；
6. 公式是否省略了 batch、head、mask 或边界项；
7. 复杂度描述的是连接数、FLOPs、显存还是实际延迟。

局部页面可以省略不影响主题的 batch 维或 bias，但必须说明省略不会改变核心计算。符号一致性的目标不是消除所有局部变量，而是让读者能从定义、形状和运算恢复完整含义。
