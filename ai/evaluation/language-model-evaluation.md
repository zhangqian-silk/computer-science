# 语言模型评估：概率质量、可比性与泛化

语言模型首先是条件概率模型。最直接的评估是看它给测试序列分配多大概率；但分词、测试域和数据污染都会改变结果，低困惑度也不等于生成事实可靠。

::: info 符号与约定
沿用[数学与符号约定](../foundations/math-notation.md)。$w_t$ 是第 $t$ 个测试 token，$T$ 是参与统计的 token 数，$w_{<t}$ 是位置 $t$ 之前的上下文，$P_\theta$ 是参数为 $\theta$ 的语言模型；$\operatorname{NLL}$ 是平均负对数似然，$\operatorname{PPL}$ 是困惑度，$\log$ 默认表示自然对数。
:::

---

## 负对数似然与困惑度

对测试 token 序列：

$$
\operatorname{NLL}
=
-\frac{1}{T}\sum_{t=1}^{T}
\log P_\theta(w_t\mid w_{<t})
$$

困惑度为：

$$
\operatorname{PPL}=\exp(\operatorname{NLL})
$$

NLL 越小，模型给真实下一 token 的平均概率越高。PPL 可以直观理解为指数化的不确定性，但这种解释只在相同 token 单位和评测协议下成立。

假设 4 个测试位置上，模型给真实下一 token 的概率分别是 $0.8,0.5,0.25,1.0$：

$$
\operatorname{NLL}
=
-\frac{1}{4}\log(0.8\times0.5\times0.25\times1.0)
=-\frac{1}{4}\log0.1
\approx0.576
$$

$$
\operatorname{PPL}=e^{0.576}\approx1.78
$$

不能先计算每个样本的 PPL 再简单平均，因为指数是非线性的。应先汇总所有有效 token 的负对数概率，再按同一单位归一化，最后指数化。

---

## 什么时候不能直接比较 PPL

不同 tokenizer 会把同一文本切成不同 token 数量。一个词表用单 token 表示的片段，在另一个词表中可能拆成多个预测事件。因此比较时至少固定：

- 原始测试文本与清洗方式；
- tokenizer 与词表；
- 是否添加起止或特殊 token；
- 上下文截断和滑窗策略；
- 对 padding、文档边界与首 token 的处理。

若必须跨分词比较，可报告按字符、字节或原始文本长度归一化的 NLL，但仍需说明单位。

测试文本长于模型窗口时还要规定滑窗方式。若每个窗口都从头计算并对重叠 token 重复计分，结果会受到重复次数影响；若窗口完全不重叠，窗口开头 token 又会缺少本可利用的左侧上下文。常见做法是让窗口重叠，但只对每次新增的目标 token 计分，并记录 stride 与最大上下文长度。

句子或文档边界也会改变条件信息。连续拼接所有文档可能允许模型跨文档读取，逐文档重置则会减少上下文；二者都可以使用，但必须与实际使用场景一致。

---

## 离散覆盖与连续泛化

N-gram 需要报告未登录词、未见 N-gram 比例以及平滑方案；否则零频事件会主导 PPL。神经模型不会因为组合未见就必然给零概率，但仍可能在低频词、长尾语法和领域迁移上退化。

可用受控集合检查泛化：

- 替换实体但保持句法；
- 改变依赖距离；
- 切换主题、体裁或时间范围；
- 分别报告高频与低频 token；
- 对最差 NLL 样本做错误归因。

这些实验判断模型是否共享规律，而不是只记忆测试分布附近的字符串。

---

## 污染与切分

若测试文本出现在训练语料中，PPL 和下游准确率都会被高估。时间切分、来源去重、近重复检测和保密测试集可降低风险。公开 benchmark 还可能通过后续网页、答案解析或模型生成数据进入训练集。

污染无法仅靠模型高分证明或排除，应记录训练数据范围、去重方法和测试集发布时间，并把结论限制在可验证范围内。

---

## 概率指标与任务指标

PPL 衡量测试 token 的概率分配，不直接衡量：

- 长答案是否忠实于证据；
- 指令是否完成；
- 事实是否正确；
- 解码后文本是否多样；
- 工具调用是否成功。

生成系统还受 prompt、temperature、top-p 和停止条件影响，应结合[生成评估](./generation-evaluation.md)。长上下文能力还需检查长度和证据位置，见[长上下文评估](./long-context-evaluation.md)。

概率还可以检查校准：当模型给某类事件约 80% 置信度时，这类事件是否约有 80% 正确。下一 token 词表很大，常按置信度区间、候选集合或下游选择任务分析。校准差不一定改变 argmax 准确率，却会影响风险阈值、拒答和候选重排。

比较两个模型时，应按文档、句子或其他独立单位做配对分析，并使用 bootstrap 等方法估计差值区间。token 数量很大不表示所有 token 相互独立；把每个 token 当作独立样本会低估不确定性。

---

## 最小报告项

一个可复核的语言模型结果应包含：模型与 tokenizer 版本、测试集及切分、有效 token 数、上下文长度、滑窗方式、NLL/PPL 的单位、置信区间或多切分结果，以及已知污染风险。
